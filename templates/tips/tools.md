# Curated Developer Tools

One-line descriptions so you know whether to click before you click.

---

**Devbox** — Isolated, reproducible dev environments using Nix under the hood. Like Docker for your shell: define tools in `devbox.json`, `devbox shell` drops you into an environment with exact versions. No system pollution.
https://www.jetify.com/devbox/

**Difftastic** — Structural diff tool that understands code syntax. Instead of line-by-line diffs, it shows semantic changes (moved brackets, renamed variables). Replaces `git diff` for reviewing code changes.
https://difftastic.wilfred.me.uk/

**Testcontainers** — Library (Java, Go, Python, Node…) that spins up real Docker containers in tests and tears them down after. The idiomatic alternative to mocking databases or external services.
https://testcontainers.com/

**mise** (formerly rtx) — Universal version manager for Node, Python, Ruby, Go, Java, and 200+ other tools. Single config file (`.mise.toml`) replaces nvm + pyenv + rbenv + sdkman. Fast (written in Rust).
https://mise.jdx.dev/getting-started.html

**Warp** — Terminal emulator with IDE-like features: block-based output (scroll per command), AI command suggestions, collaborative sharing. Replaces iTerm2/Alacritty for teams that want more than a raw terminal.
https://www.warp.dev/

**GitButler** — Git client that lets you manage multiple branches simultaneously as "virtual branches" — work on several features at once without the stash/switch/apply cycle.
https://gitbutler.com/

**tsoa** — TypeScript-first framework that generates OpenAPI specs and Express/Fastify routes from TypeScript decorators. Eliminates manual API spec maintenance.
https://github.com/lukeautry/tsoa

**SemanticMerge** — Merge tool that understands code structure (not text). Resolves conflicts by understanding what moved vs. what changed, dramatically reducing false conflicts in refactors.
https://docs.plasticscm.com/semanticmerge/

**Pyright** — Static type checker for Python (also the engine behind Pylance in VS Code). Faster than mypy, stricter mode available, installable as a CLI or pre-commit hook.
https://pypi.org/project/pyright/
