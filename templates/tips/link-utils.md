# Useful Developer Learning Resources

A curated collection of references that hold up over time.

---

**rbenv cheatsheet** — Quick reference for rbenv commands: installing Ruby versions, setting local/global versions, managing gemsets.
https://devhints.io/rbenv

**Roadmap.sh** — Visual, community-maintained skill roadmaps for frontend, backend, DevOps, and more. Useful for identifying gaps in a learning path or onboarding a new team member.
https://roadmap.sh/

**FullStack.cafe** — Curated technical interview questions organized by technology and level. Good for interview prep or verifying conceptual understanding.
https://www.fullstack.cafe/

**GNOME Shell Extension Installer** — CLI tool for installing GNOME Shell extensions without a browser. Useful on headless setups or when the browser extension approach fails.
https://github.com/brunelli/gnome-shell-extension-installer/releases

**npm global packages list** — How to list globally installed npm packages with their versions. Helpful when debugging PATH issues or auditing what's installed system-wide.
```bash
npm list -g --depth=0
```
Reference: https://medium.com/@alberto.schiabel/npm-tricks-part-1-get-list-of-globally-installed-packages-39a240347ef0
